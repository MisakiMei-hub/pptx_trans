# PPTX_trans

PPT 翻译工具（繁体中文 → 任意语言）

![GitHub stars](https://img.shields.io/github/stars/MisakiMei-hub/pptx_trans?style=social)
![Python](https://img.shields.io/badge/python-3.8%20%7C%203.9%20%7C%203.10%20%7C%203.11-blue)

## 使用说明

使用前需安装缺失的库：

```bash
pip install deep-translator python-pptx
```

## 语言设置

此行控制语言：`translator = GoogleTranslator(source='zh-TW', target='zh-CN')`，默认繁体中文翻译为简体中文，自行替换
